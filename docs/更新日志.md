# 更新日志

本文件用于维护 QQ 机器人项目各版本的功能变更、问题修复和兼容性调整。

## v1.1.1

### 优化

- 统一兼容 NapCat 和 SnowLuma 的引用消息处理，支持从 `ReplyMessage.chain` 或 `ReplyMessage.text` 获取引用正文。
- SnowLuma 引用背包中的 Markdown 链接会自动剥离链接外壳，恢复物品名称和拥有数量文本。
- “引用背包 一键上架/炼金”命令同时兼容消息参数和消息链文本，避免 SnowLuma 下命令未触发。
- 引用背包消息无法回填引用链时，增加当前消息链文本兜底解析。
- 补充极品装备、无上仙器等物品格式的识别。

### 修复

- 修复 SnowLuma 环境下引用背包查上架价格无响应的问题。
- 修复 SnowLuma 环境下引用背包一键上架、一键炼金无法识别物品的问题。
- 修复 SnowLuma 卡片形式的“天机悬赏令”正文不在普通 `message` 参数中，导致悬赏令价格查询未触发的问题。
- 悬赏令价格查询统一从消息参数和消息链文本中识别悬赏内容，兼容 Markdown 卡片格式。

## v1.0.9

### 新增

- 新增“启用消息转发”和“开启消息转发”命令。
- 新增“关闭消息转发”命令。
- 消息转发开关支持持久化，机器人重启后自动恢复。
- “提醒帮助”和“当前设置”中增加消息转发说明及状态显示。
- Web 配置页面增加“启用消息转发到控制群”选项。

### 优化

- 优化购买提醒的本群开关，支持机器人自身发出的“开启/关闭本群购买提醒”命令。
- 购买提醒消息、帮助文本和操作结果中的命令示例被机器人再次处理时，不再误触发提醒设置命令。
- 优化 SnowLuma Markdown 消息转发，清理版本标记、艾特链接等无关内容。
- 优化秘境、结算等多处理器同时收到消息时的转发流程，改为合并判定并保证同一消息只转发一次。
- 转发正文从消息链中的 Markdown 文本段提取，兼容 SnowLuma 的 `at + markdown + inline_keyboard` 消息结构。
- 兼容 NapCat/SnowLuma 验证码消息转发，去除 `inline_keyboard` JSON 和图片占位文本，保留手动点击提示及按钮序号。
- 统一验证码人工处理提示格式，不再把 NapCat 的原始图片/键盘协议内容作为正文转发。
- 购买提醒帮助和操作结果改为纯文本发送，避免 SnowLuma 显示“不支持的元素类型”。

### 修复

- 修复 SnowLuma 环境下符合条件的秘境消息偶发无法转发到控制群的问题，并避免转发异常中断同一条消息的其他处理。
- 修复 SnowLuma 验证码消息包含 Markdown 图片尺寸、版本号等无关数字时，导致题目序号识别错误的问题。
