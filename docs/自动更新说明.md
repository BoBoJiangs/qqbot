# 自动更新说明

发布服务器的 `update.json` 使用 `force` 控制新版本的安装方式：

```json
{
  "version": "1.1.17",
  "jarUrl": "bot.jar",
  "notes": "填写本次更新说明",
  "force": false
}
```

以上版本号仅为格式示例，发布时应与实际 JAR 的版本号一致。

- `force: true`：检测到更高版本时自动安装，并按本地 `autoRestart` 设置决定是否重启。
- `force: false`：定时检查和启动检查都不自动下载安装，只能发送“立即更新”安装。
- 不提供 `force` 或填写 `null`：与 `false` 相同。
- 无论 `force` 如何设置，同版本或低版本均不会重新安装，避免强制更新后反复重启。

“检测版本更新”和“版本更新日志”继续可用；检测到手动更新版本时会提示发送“立即更新”。

本地 `update.enabled` 必须启用；自动更新还需要 `update.autoApply: true`。
`autoApply: false` 时保留手动更新，服务端 `force: true` 不会绕过该本地开关。
“立即更新”安装完成后会触发重启。

此规则需要客户端运行支持上述逻辑的新包。旧客户端仍遵循旧逻辑，不能仅靠把服务端 `force` 改为 `false` 关闭其自动更新。
